LumaTape · Windows x64 · Preview
English · Русский: START-HERE.txt

First launch
1. Install LumaTape with LumaTape_<version>_x64-setup.exe.
   For a portable copy, extract the entire ZIP and open lumatape.exe;
   keep the engine folder and all its files beside it.
2. Open a game in windowed or borderless mode.
3. Left- or right-click the LumaTape icon in the Windows notification
   area and open Settings….
4. Choose the game window and effect, then Turn on, and return to the game.
   Try VHS Tape for a first look.

Quick actions remain in the tray. Settings open on demand; launching LumaTape
again also opens them in the existing instance. Closing settings normally
leaves the effect running.
If Windows hides the icon, open the notification area's overflow menu.
The interface follows the Windows display language at launch:
Russian for RU, English for other languages.

Turning it off
Turn off removes the effect and restores window/display-mode changes
made by LumaTape. Quit closes the application.
New-profile shortcuts:
  Ctrl+Shift+9: turn the effect on / off.
  Ctrl+Shift+0: emergency off and restore.
Existing shortcuts are preserved; see them under Settings → Hotkeys.

Make the window 4:3
In settings, choose Make window 4:3. LumaTape resizes the window once,
without changing Windows resolution. If the game stretches the image,
select 4:3 in the game too. Restore original format restores LumaTape's changes.
System resolution is a separate option: after switching, choose Keep within
15 seconds or Revert. Closing settings during confirmation cancels the
resolution change and turns the effect off.

Try it without a game
Tools → Test scene opens a test window. Select it under Game.
F11 or Alt+Enter makes it fullscreen; Escape returns it to a window.

Add your own effect
Add effect from file… opens .lumatape.glsl.
After validation, it appears in the menu; a failed import keeps the working effect.
Examples and a ready-to-use AI prompt: docs/shaders/README.en.md.
LumaTape itself makes no AI requests.

Updates and help
Tools → Check for updates… checks for a new version.
Installing an update requires confirmation. Update a ZIP copy by extracting
a new package separately; settings are saved outside the application folder.
Tools → Last error… shows the reason for a failure.
Copy diagnostics copies text; you decide whether to send it.
Settings and limitations: docs/README.en.md.
Report a problem: https://github.com/aiwaki/lumatape/issues

Compatibility
Windows 10 version 2004 or later, x64, OpenGL 3.3, SDR.
Games must run in windowed or borderless mode; HDR and exclusive fullscreen
are unsupported. Settings need Microsoft Edge WebView2 Runtime: the installer
downloads it if needed; portable ZIP users should install it separately.
Development tools are not required to run the app.
This is a preview: it has been tested in Windows through Parallels; physical GPU
support and real-game compatibility still need validation.
