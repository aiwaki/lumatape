LumaTape добавляет CRT/VHS-эффекты поверх окна игры: телевизионные строки,
мягкое свечение и искажения видеокассеты. В комплекте пять пресетов, а свою
коллекцию можно пополнить собственными эффектами. Экран можно сделать
скруглённым или выпуклым, как у старого телевизора.
Сам телевизор с антресолей доставать не придётся.

Это бесплатная программа с открытым исходным кодом для Windows 10/11 x64.
Пульт управления находится в системном трее, отдельного окна настроек нет.
Язык интерфейса выбирается по Windows: русский или английский.

## Первое включение

1. В [последнем релизе](https://github.com/aiwaki/lumatape/releases/latest) скачайте
   и запустите `LumaTape_<версия>_x64-setup.exe`. Для переносной копии распакуйте
   весь ZIP и откройте `lumatape.exe`; оставьте папку `engine` рядом.
2. Откройте игру в оконном или borderless-режиме. Нажмите на значок LumaTape
   в области уведомлений Windows и выберите окно в меню «Игра».
3. Выберите «Эффект», нажмите «Включить» и вернитесь в игру.
   Начать можно с VHS Tape. Эффекты можно переключать во время игры;
   выбор применяется сразу.
4. «Выключить» убирает эффект и восстанавливает изменения, сделанные LumaTape.
   «Выход» завершает приложение.

Можно сначала поиграться с тестовой картинкой: откройте «Сервис → Тестовая сцена»,
затем выберите её в «Игра». Игра для этого не нужна.
F11 разворачивает тестовую сцену на весь экран, Escape возвращает в окно.

## Клавиши

| Клавиши нового профиля | Действие |
|---|---|
| Ctrl+Shift+9 | Включить / выключить эффект |
| Ctrl+Shift+0 | Аварийно отключить и восстановить |

Прежние назначения сохраняются. Они показаны в «Настройки → Горячие клавиши».

## Своя коллекция эффектов

Выберите «Добавить эффект из файла…» и откройте `.lumatape.glsl`. После проверки
он появится в меню «Эффект».
В [руководстве](docs/shaders/README.md) есть примеры и готовый запрос нейросетям.

Для запуска нужны Windows 10 версии 2004 или новее, x64, OpenGL 3.3 и SDR.
Запускайте игры в окне или borderless-режиме; HDR и exclusive fullscreen
не поддерживаются.
Это предварительная версия (preview). Работа проверена в Windows через Parallels;
физический GPU и совместимость с реальными играми ещё требуют проверки.
