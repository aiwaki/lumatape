LumaTape · Windows x64 · Preview
Русский · English: START-HERE.en.txt

Первый запуск
1. Установите LumaTape через LumaTape_<версия>_x64-setup.exe.
   Для переносной копии распакуйте весь ZIP и откройте lumatape.exe;
   папка engine со всеми файлами должна остаться рядом.
2. Откройте игру в окне или в режиме без рамки (borderless).
3. Нажмите на значок LumaTape в области уведомлений Windows
   левой или правой кнопкой и откройте «Настройки…».
4. Выберите окно игры и эффект, затем «Включить» и вернитесь в игру.
   Для первого знакомства попробуйте VHS Tape.

Быстрые команды остаются в трее. Окно настроек открывается по запросу;
повторный запуск LumaTape тоже открывает его в существующем экземпляре.
Обычное закрытие настроек не выключает эффект.
Если значок скрыт Windows, откройте область дополнительных значков.
Язык интерфейса определяется по языку Windows при запуске:
русский для RU, английский для остальных языков.

Как отключить
«Выключить» убирает эффект и восстанавливает изменения окна/видеорежима,
сделанные LumaTape. «Выход» завершает приложение.
В новом профиле:
  Ctrl+Shift+9 — включить / выключить эффект.
  Ctrl+Shift+0 — аварийно отключить и восстановить.
Старые назначения сохраняются; они показаны в «Настройки → Горячие клавиши».

Сделать окно 4:3
В настройках нажмите «Сделать окно 4:3». LumaTape один раз меняет размер окна,
не меняя разрешение Windows. Если игра растягивает картинку, выберите 4:3 и в ней.
«Вернуть исходный формат» восстанавливает собственные изменения.
Системное разрешение — отдельный вариант: после переключения нажмите «Оставить»
за 15 секунд или «Вернуть». Закрытие настроек во время подтверждения отменяет
смену разрешения и выключает эффект.

Попробовать без игры
«Сервис → Тестовая сцена» открывает тестовое окно. Выберите его в «Игра».
F11 или Alt+Enter — на весь экран; Escape — обратно в окно.

Добавить свой эффект
«Добавить эффект из файла…» открывает .lumatape.glsl.
После проверки эффект появляется в меню; неудачный импорт не заменяет рабочий.
Примеры и готовый запрос нейросетям: docs/shaders/README.md.
Само приложение не обращается к нейросетям.

Обновления и помощь
«Сервис → Проверить обновления…» проверяет новую версию.
Установка обновления требует подтверждения. ZIP-копию обновляйте
распаковкой нового комплекта отдельно; настройки сохраняются вне папки приложения.
«Сервис → Последняя ошибка…» показывает причину сбоя.
«Скопировать диагностику» копирует текст; отправлять его нужно самостоятельно.
Настройки и ограничения: docs/README.md.
Сообщить о проблеме: https://github.com/aiwaki/lumatape/issues

Совместимость
Windows 10 версии 2004 или новее, x64, OpenGL 3.3, SDR.
Игры должны работать в окне или borderless; HDR и exclusive fullscreen
не поддерживаются. Для окна настроек нужен Microsoft Edge WebView2 Runtime:
установщик скачает его при необходимости; для ZIP-копии установите его отдельно.
Средства разработки для запуска не нужны.
Это предварительная версия (preview): работа проверена в Windows через Parallels, а физический GPU
и совместимость с реальными играми ещё требуют проверки.
