# Документация LumaTape

[О проекте](../README.md) · Русский · [English](README.en.md)

## Первое включение

1. Скачайте `LumaTape_<версия>_x64-setup.exe` из
   [последнего релиза](https://github.com/aiwaki/lumatape/releases/latest) и запустите
   установщик. Для переносной копии распакуйте весь ZIP и откройте `lumatape.exe`;
   папка `engine` со всеми файлами должна остаться рядом.
2. Откройте игру в окне или в режиме без рамки (borderless).
3. Нажмите на значок LumaTape в трее, у часов Windows, и откройте «Настройки…».
   Если значок скрыт, откройте область дополнительных значков.
4. Выберите окно игры и эффект, нажмите «Включить» и вернитесь в игру.
   Начать можно с VHS Tape. Эффекты можно менять во время игры — выбор применяется сразу.

Для эффекта на весь экран выберите в игре «Полноэкранный без рамки»
(borderless fullscreen). LumaTape обрабатывает содержимое выбранного окна:
если она занимает экран, эффект тоже занимает экран. Маленькое окно автоматически
не увеличивается; захват всего рабочего стола не поддерживается.

«Выключить» убирает эффект и восстанавливает изменения окна или видеорежима,
сделанные LumaTape. «Выход» завершает приложение. Быстрые действия остаются в трее,
а отдельное окно объединяет выбор игры, эффекта, формата и показатели скорости.
При первом запуске появляется только трей; повторный запуск открывает настройки
существующего экземпляра. Обычное закрытие настроек освобождает их окно и не
выключает эффект. Исключение — неподтверждённая смена разрешения Windows: закрытие
отменяет её и выключает эффект.

LumaTape бесплатна, исходный код открыт.

Для запуска нужны Windows 10 версии 2004 или новее, x64, OpenGL 3.3 и SDR.
Окно настроек использует Microsoft Edge WebView2 Runtime. Установщик включает
bootstrapper, который при необходимости скачивает и устанавливает runtime;
для ZIP-копии он должен быть установлен отдельно. Средства разработки не нужны.
HDR и эксклюзивный полноэкранный режим (exclusive fullscreen) не поддерживаются.

Это предварительная версия (preview). Программа проверена в Windows через
Parallels; работа на физическом GPU и совместимость с реальными играми
ещё требуют проверки.

## Тестовая сцена и свои эффекты

Чтобы попробовать эффекты без игры, откройте «Сервис → Тестовая сцена»
и выберите её в меню «Игра». F11 или Alt+Enter разворачивает сцену на весь экран,
Escape возвращает в окно.

В меню «Эффект» есть пять готовых пресетов. Для своего шейдера выберите
«Добавить эффект из файла…» и откройте файл `.lumatape.glsl`.
После проверки эффект появится в меню. В [руководстве](shaders/README.md)
есть примеры и готовый запрос нейросетям.

## Обновления

Проверить обновления можно через «Сервис → Проверить обновления…».
Установку нужно подтвердить. Переносную ZIP-копию обновляйте распаковкой
нового комплекта отдельно.

## Запуск с Windows

«Сервис → Запускать при входе в Windows» включает запуск LumaTape в трее при входе
текущего пользователя. Автозапуск доступен только после установки через
`LumaTape_<версия>_x64-setup.exe`; в переносной ZIP-копии включить его нельзя.
По умолчанию автозапуск выключен. Эта настройка не включает эффект.

Если отключить LumaTape в разделе «Автозагрузка» Диспетчера задач, приложение
сохранит этот выбор до явного повторного включения автозапуска.
Обновление сохраняет настройку; удаление приложения убирает запись автозапуска.

## Настройки изображения

### Обработка

Новый профиль выбирает автоматическую обработку: сначала GPU, затем совместимый
CPU только при распознанной несовместимости драйвера с обменом текстурами между
Direct3D и OpenGL (GPU interop). Одной capture DLL недостаточно: драйверу нужна поддержка
`WGL_NV_DX_interop2`. Другие ошибки захвата не вызывают переход на другой способ
обработки. Выбор в сохранённых ручных профилях не меняется.
CPU ограничен 30 кадрами/с; это предел, а не гарантированная скорость. В настройках
разделены «Новые кадры» и «Показ»: повторный показ того же изображения не считается
новым кадром. На ultrawide нагрузка зависит и от площади захватываемого окна;
уменьшение окна снижает объём переноса. Lightweight поддерживает только эффекты поверх окна;
полноценная обработка цвета требует Full.

### Форма экрана

Плоский экран не добавляет рамку. Скруглённый CRT добавляет
сглаженные непрозрачные углы, затемнение края и стекло, сохраняя положение пикселей.
Выпуклый CRT искривляет изображение и требует Full. Радиус считается относительно
короткой стороны изображения. Выключение убирает форму вместе с эффектом.

### Искажения изображения

Клавиатура и мышь работают в обоих режимах.
«Точные клики» допускают встроенную выпуклость: известная геометрия используется
для проекции рисунка системного курсора. Windows-координаты, события кнопок,
колесо, Raw Input и захват мыши не меняются. Это не универсальное переназначение
игрового ввода. Crop/Stretch, нестандартный DAR и пользовательский `warp` требуют
явного выбора «Разрешить произвольные искажения». Для своего `warp` проекция
системного курсора отключена; пометка автора `preserve` сама по себе не доказывает
совпадение кликов.

Если часть окна выходит за пределы экранов, выпуклый эффект с проекцией курсора
приостанавливается: обычный курсор Windows не может попасть в скрытую часть окна.
Верните окно целиком на экран — эффект возобновится без повторного включения.

### Масштаб и пропорции старых игр

Fit сохраняет весь кадр; Crop заполняет область,
обрезая края; Stretch растягивает изображение. Обычно оставляйте исходные пропорции.
«Пропорции старых игр» (DAR) исправляют пропорции изображения, например кадра
320×200, рассчитанного на экран 4:3 с неквадратными пикселями. Размер окна и
отрисовка самой игры не меняются. Это не способ превратить любую игру в 4:3:
правильное изображение 16:9 при таком изменении сожмётся, а круг станет овалом.
1280×1024 — это 5:4, а не 4:3. Fit 16:9 внутри области 4:3 по-прежнему показывает
изображение 16:9.

### Формат 4:3

Начните с «Сделать окно 4:3» в настройках. LumaTape один раз меняет клиентскую
область выбранного окна, вписывая его в рабочую область монитора с учётом рамки,
заголовка и DPI. На широком мониторе окно располагается по центру; разрешение
Windows не меняется. Результат проверяется, а при отказе изменения откатываются.
Этот способ не закрывает края маской и не добавляет искусственные поля к изображению.
Он меняет размер самого окна: полноэкранное окно без рамки тоже уменьшится и
перестанет занимать весь широкий экран.

Игра сама решает, как отрисовать содержимое нового окна. Если она растягивает
широкую картинку, выберите 4:3 и в её настройках. Если игра возвращает прежний
размер, LumaTape показывает, что формат больше не применён; повторить изменение
можно той же кнопкой. Постоянно менять размер наперекор игре приложение не будет.
«Вернуть исходный формат» восстанавливает собственные изменения, сохраняя
включённость эффекта; «Выключить» также отключает эффект. Более поздние изменения
окна пользователем или игрой не перезаписываются. Маска осталась только для
совместимости со старыми JSON/CLI-профилями.

«Разрешение Windows…» использует только перечисленные Windows видеорежимы,
проверяет кандидата и временно применяет его без записи в реестр. Окно настроек
открывается до переключения и сразу показывает обратный отсчёт с кнопками
«Оставить» и «Вернуть». На подтверждение есть 15 секунд. «Вернуть» сохраняет
включённость эффекта, если восстановление прошло успешно; закрытие окна во время
ожидания выполняет аварийное отключение. Отдельный watchdog восстанавливает
режим при таймауте, выходе или падении основного процесса. Более позднее обнаруженное
изменение пользователя не перезаписывается. Win32 не даёт атомарного compare-and-set:
короткая гонка или смена туда-обратно между опросами не исключены. Одновременное
завершение обоих процессов и отказ ОС/драйвера watchdog не покрывает. GPU/панель
могут растянуть 4:3; универсального управления GPU scaling нет.

## Клавиши, язык и хранение

| Клавиши нового профиля | Действие |
|---|---|
| Ctrl+Shift+9 | Включить / выключить эффект |
| Ctrl+Shift+0 | Аварийно отключить и восстановить изменения |

Прежние сочетания сохраняются и показаны в «Настройки → Горячие клавиши».
Альтернативная пара —
Ctrl+Alt+F9 / Ctrl+Alt+F10. При конфликте регистрации новая пара не заменяет рабочую.
Проверка клавиш в меню различает успешную регистрацию и фактическое получение;
сами команды во время проверки продолжают действовать.

На Mac Alt соответствует Option ⌥, а Control — не Command. F-клавишам иногда
нужен Fn; доставка зависит от Parallels. Приложение не меняет настройки хоста.
[Клавиши Windows на Mac](https://support.apple.com/guide/mac-help/windows-keys-on-a-mac-keyboard-cpmh0152/mac),
[клавиатура в Parallels](https://kb.parallels.com/en/114309).
Если в Parallels при смене фокуса меняются скорость мыши или состояние кнопки,
проверьте Smart Mouse: в проверенной конфигурации помог режим
**Don't optimize for games**. Это настройка VM, а не LumaTape.

Язык выбирается при запуске по языку интерфейса Windows: для RU используется
русский, для остальных — английский. Региональные форматы не влияют на выбор;
после смены языка Windows перезапустите
приложение. Названия игр, пресетов и своих шейдеров не переводятся. Сообщения
ОС/драйверов в технических подробностях могут оставаться на исходном языке.

Настройки и журнал: `%APPDATA%\LumaTape`. Библиотека шейдеров:
`%LOCALAPPDATA%\LumaTape\Shaders`. Сохранённые профили JSON/CLI продолжают работать:
интенсивность 0 обходит фильтр и форму, сохраняя независимый 4:3. Трей и настройки используют
100% при явном выборе или включении эффекта; простое чтение старого профиля
не переписывает его значения.

## Диагностика и ограничения

При проблеме откройте «Сервис → Последняя ошибка…».
[Сообщить о проблеме](https://github.com/aiwaki/lumatape/issues).

«Скопировать диагностику» исключает снимки, полные пути, код шейдеров и названия
чужих окон; автоматической отправки нет. Локальный JSON-журнал использует
ограниченную очередь и непрерывную ротацию: текущий файл и три резервных,
до 4 MiB каждый. Потерянные события и ошибки записи учитываются.

Отдельно измеряются отправка команд с CPU (CPU submission), выполнение шейдера
на GPU (GPU shader time), перенос кадра через CPU (CPU transfer) и возраст
захваченного кадра. Частота новых захваченных изображений и частота их показа
измеряются отдельно; это не FPS внутри игры и не частота монитора. У измерения
есть время наблюдения и состояние актуальности. На паузе текущая скорость
недоступна; последнее измерение, если оно есть, хранится отдельно со своей датой.
Ни одна из этих метрик не показывает полную задержку от ввода до экрана. `null` обозначает
отсутствующее измерение. Запись диагностического PNG синхронизирует GPU
и не подходит для измерения производительности.

Full работает в SDR и отказывает при активном HDR/Advanced Color. Exclusive
fullscreen, защищённые окна/DRM, античит, захват всего монитора в Full и совместимость
с каждой игрой не заявлены. Windows может показывать рамку-индикатор захвата.
При перемещении, изменении размера окна или потере фокуса эффект может временно
скрываться, показывая оригинал. WGC может не присылать новые кадры для статичного
изображения: уже проверенный кадр разрешено повторять только после проверки
источника, устройства и геометрии, без ожидающей CPU-копии. Задержка переноса не
считается статичным изображением. После сбоя показ возобновляется лишь после
серии свежих кадров. При быстром повторении сбоя эффект остаётся на паузе;
выключите и включите его для новой попытки. Это не подтверждает исправление
на конкретном физическом GPU: такой прогон ещё нужен.

Системный курсор проецируется только для известной встроенной геометрии.
XOR-инверсия заменяется белой формой с чёрной обводкой: это сохраняет видимость
и активную точку курсора, но не воспроизводит инверсию фона. Тайминг анимированных
системных курсоров не воспроизводится. Курсор, нарисованный игрой, остаётся частью её кадра.
Отдельный watchdog восстанавливает обычный курсор после сбоя или отсутствия
кадров более 500 ms. Если движок полностью завис, сама замершая картинка может
оставаться до его возобновления или завершения. Исправление двоения курсора
на границе окна Parallels пока не подтверждено физическим наблюдением.

## Сборка и проверки

Текущая оболочка — нативный трей Tauri и загружаемые по запросу локальные настройки
на HTML/CSS/JavaScript. React-прототипы и отдельный Go/Win32-интерфейс сохранены
в репозитории, но не входят в текущий интерфейс.

Собирайте Windows x64 с закреплёнными зависимостями. Нужны Go ≥1.23, Rust,
Node/npm для Tauri CLI, Python ≥3.11, Git, CMake ≥3.24 и Visual Studio 2022
Build Tools с **Desktop development with C++**, C++20 и Windows SDK ≥10.0.26100.
SDK сборки новее минимальной ОС запуска; используемые API ограничены build 19041.
В командах ниже `0.3.1` — пример номера версии. Подставьте версию из
`desktop/package.json`, `Cargo.toml` и `tauri.conf.json`; она должна совпадать
во всех трёх файлах.

```powershell
.\scripts\build-desktop.ps1 -Version 0.3.1
```

Скрипт собирает нативные DLL, Go engine/testcard/watchdog, ресурсы и Tauri host,
создаёт чистый ZIP, SHA256, метаданные и лицензии. Сборка React/Vite не нужна.
Подписанный NSIS-пакет собирается отдельно по [инструкции обновлений](UPDATES.md).

Для cross-build на macOS/Linux нужны target `x86_64-pc-windows-msvc`, `cargo-xwin`,
LLVM и явно подготовленная CMake install-папка native-части:

```sh
scripts/build-desktop.sh /absolute/native-install 0.3.1
```

Подготовка ресурсов и локальный запуск описаны в
[документации оболочки Tauri](../desktop/src-tauri/README.md).

```sh
sh scripts/check.sh                        # Go unit/race/vet + Windows cross-build
sh scripts/validate-shaders-macos.sh        # встроенные шейдеры, Mac CGL/OpenGL
sh scripts/validate-custom-shaders-macos.sh # пользовательские шейдеры, Mac CGL/OpenGL
cd desktop && npm run test:host            # Rust host/menu/updater
npm run test:settings                      # модель текущего окна настроек
```

Это отдельные уровни проверки: переносимая логика, Mac CGL, совместимость CPU-переноса
в Windows и физический GPU под Windows. Прохождение unit-тестов или кросс-сборки не доказывает
качество изображения, корректность реальных кликов и совместимость конкретной игры.
Для проверки в Windows используйте [протокол](WINDOWS_VALIDATION.md) и собственную
тестовую сцену. `lumatape-testcard.exe --fullscreen --pointer-test` запускает сцену
проверки курсора без рамки; `--color-field` полезен для оценки шума и цветности.

Отдельный `scripts/build-windows.ps1` собирает legacy/CLI-приложение Go с Win32 UI,
а не основной Tauri host. Его `--snapshot` служит диагностике, не игровому режиму.
Тесты сохранённых `desktop/ui` и прототипов не проверяют текущие трей и настройки.

Настройки и геометрия, не зависящие от ОС, находятся в `internal/config`,
`internal/geometry`, `internal/display`; шейдеры — в `internal/render/shaders`,
платформенный слой — в `internal/platform`. Модель трея находится в
`desktop/src-tauri/src/tray_model.rs`, обработка команд — в `tray.rs`,
системные диалоги — в `native_dialog.rs`, окно настроек — в `settings.rs` и
`desktop/tray-assets/`.
