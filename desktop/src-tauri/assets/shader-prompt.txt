Создай пользовательский шейдер для LumaTape v1.
Желаемый эффект: [замени эту строку своим описанием].

Верни один готовый файл .lumatape.glsl, без объяснений. Можно использовать один блок ```glsl.
Это однопроходный фрагментный фильтр SDR sRGB для GLSL 330 core, не Shadertoy и не ReShade.
Создай законченный внешний вид: пользователь выбирает эффект и включает его, без ползунков и ручной настройки. Все художественные значения задай константами внутри GLSL; parameters оставь пустым массивом [].
В начале обязателен комментарий /* LumaTape с JSON и закрытием */:
{
  "version": 1,
  "name": "Название эффекта",
  "description": "Короткое описание",
  "coordinates": "preserve",
  "parameters": []
}

После заголовка определи vec3 lumatape(vec2 uv). Приложение предоставляет:
- uv: координаты изображения 0..1, начало сверху слева;
- vec3 ltSample(vec2 uv): выборка игры в sRGB, с готовым crop и clamp;
- vec2 ltResolution: размер области изображения в физических пикселях;
- float ltTime: время в секундах (0 при замороженном шуме);
- float ltParams[8]: сохранён для совместимости файлов v1; в новом файле с parameters: [] все слоты равны 0, не используй их для эффекта.
Верни RGB sRGB. Desktop применяет выбранный эффект на 100%; весь желаемый вид должен задаваться кодом. Приложение само делает непрозрачную alpha, форму CRT и 4:3 — не дублируй их. В JSON/CLI совместимости остаётся общая интенсивность и bypass при 0%; не применяй эту общую интенсивность внутри функции.
ABI v1 по-прежнему допускает до 8 параметров старых файлов: уникальные имена, конечные min < max, 0 < step <= max-min, default внутри диапазона, границы по модулю до 1 000 000. При выборе такого файла используются его defaults, ползунков в desktop нет. Новый файл создавай с parameters: []. Не добавляй id.
Для цветового фильтра, зерна, строк или локальной мягкости укажи coordinates: "preserve". Для перемещения/искривления изображения обязательно "warp"; LumaTape потребует управление клавиатурой/геймпадом. Не заявляй preserve при смещении геометрии.
Разрешены helper-функции GLSL, математика и несколько развёрнутых выборок ltSample.
Не используй #version, #include, директивы препроцессора, main, uniforms, in/out/inout, layout, discard, имена gl_*, frag или uSource*. Циклы for/while/do в v1 не поддерживаются: разверни небольшое фиксированное число выборок вручную. Не используй текстуры, файлы, историю кадров или несколько проходов. Размер файла до 64 KiB.

Минимальный работающий пример:
/* LumaTape
{"version":1,"name":"Тёплый свет","description":"Готовый тёплый оттенок","coordinates":"preserve","parameters":[]}
*/
vec3 lumatape(vec2 uv) {
    vec3 color = ltSample(uv);
    return mix(color, color * vec3(1.08, 0.97, 0.84), 0.6);
}
