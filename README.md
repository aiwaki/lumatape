CRT и VHS для игр: телевизионные строки, мягкое свечение и искажения видеокассеты.
LumaTape накладывает эффекты на окно игры и может сделать экран скруглённым
или выпуклым, как у старого телевизора.
Сам телевизор с антресолей доставать не придётся.

В комплекте пять пресетов; свои эффекты можно добавить из файла.
Всё управление находится в системном трее, у часов Windows.
Программа бесплатная, с открытым исходным кодом. Работает на Windows 10/11 x64
и выбирает русский или английский интерфейс по языку системы.

## Первое включение

1. В [последнем релизе](https://github.com/aiwaki/lumatape/releases/latest) скачайте
   и запустите `LumaTape_<версия>_x64-setup.exe`. Для переносной копии распакуйте
   весь ZIP и откройте `lumatape.exe`; оставьте папку `engine` рядом.
2. Откройте игру в окне или в режиме без рамки (borderless). Нажмите на значок
   LumaTape в трее и выберите её окно в меню «Игра».
3. Выберите эффект в одноимённом меню, нажмите «Включить» и вернитесь в игру.
   Попробуйте VHS Tape для начала. Эффекты можно менять во время игры,
   они применяются сразу.
4. «Выключить» убирает эффект и восстанавливает изменения, сделанные LumaTape.
   «Выход» завершает приложение.

Можно сначала поиграться с тестовой картинкой без запуска игры:
откройте «Сервис → Тестовая сцена» и выберите её в меню «Игра».
F11 разворачивает тестовую сцену на весь экран, Escape возвращает в окно.

## Клавиши

| Клавиши нового профиля | Действие |
|---|---|
| Ctrl+Shift+9 | Включить / выключить эффект |
| Ctrl+Shift+0 | Аварийно отключить и восстановить |

Прежние сочетания сохранятся. Текущие клавиши показаны
в «Настройки → Горячие клавиши».

## Своя коллекция эффектов

Выберите «Добавить эффект из файла…» и откройте файл `.lumatape.glsl`.
После проверки эффект появится в меню «Эффект».
В [руководстве](docs/shaders/README.md) есть примеры и готовый запрос нейросетям.

Для запуска нужны Windows 10 версии 2004 или новее, x64, OpenGL 3.3 и SDR.
HDR и эксклюзивный полноэкранный режим (exclusive fullscreen) не поддерживаются.
Это предварительная версия (preview): пока программа проверена в Windows
через Parallels. Работа на физическом GPU и совместимость с реальными играми
ещё требуют проверки.
