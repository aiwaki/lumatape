LumaTape 0.3.1 — Windows x64 · SDR · оконные игры / borderless

ЯЗЫК / LANGUAGE
Язык меню и сообщений выбирается по языку интерфейса Windows при запуске:
русский для RU, английский для остальных языков. Для смены — перезапустите LumaTape.
The tray, dialogs and test scene follow the Windows display language at launch:
Russian for RU, English otherwise. Window titles and your shaders keep their names.
Quick start: extract everything → run lumatape.exe → select Game → Effect → Turn on.
Tools → Test scene opens a test window. F11 / Alt+Enter toggles fullscreen; Escape exits it.
Turn off restores the original display; Quit closes LumaTape.
New profile shortcuts: Ctrl+Shift+9 toggles the effect; Ctrl+Shift+0 restores the display.
Add effect from file… imports .lumatape.glsl; errors leave the working effect intact.
Settings → Image distortion: Accurate clicks limits distortion; both modes accept
keyboard and mouse. Allow arbitrary distortion may misalign visible click targets.
Tools → Check for updates… explains the channel status. This build has no configured
update channel and sends no update requests. ZIP copies do not install updates in place.

ЗАПУСК
1. Распакуйте весь комплект и запустите корневой lumatape.exe.
   Сохраните engine со всеми DLL/EXE. WebView2 не нужен.
2. Нажмите на значок LumaTape в области уведомлений левой или правой
   кнопкой мыши: оба клика открывают обычное системное меню.
   Окна приложения, панели и встроенного браузера при запуске нет.
3. Откройте игру и выберите её в «Игра». Для проверки используйте
   «Сервис → Тестовая сцена», затем выберите LumaTape test card в «Игра».
   В тестовой сцене: «На весь экран» или F11 / Alt+Enter; Escape — обратно в окно.
4. Выберите «Эффект», нажмите «Включить» и вернитесь в игру самостоятельно.
   Новый профиль использует автоматическую обработку. В Parallels при
   отсутствии GPU interop используется CPU до 30 кадров/с.
5. «Выключить» скрывает эффект, отменяет ожидающее применение и восстанавливает
   собственные изменения окна/экрана, включая 4:3. «Выход» завершает приложение.

Версия находится над «Выход / Quit». «О LumaTape / About LumaTape» открывает
GitHub проекта в браузере. До публикации репозитория адрес может возвращать404.

УПРАВЛЕНИЕ
Все основные команды находятся в трее. Другой эффект при включённом фильтре
применяется сразу. Ползунков параметров и интенсивности нет: вид задаёт шейдер.
Явный выбор эффекта и включение устанавливают интенсивность 100%.
«Включить / Выключить» — один пункт; отдельного «Стоп» нет. При активном 4:3
или незавершённом восстановлении он также предлагает «Выключить».
Верхняя строка показывает фактическое состояние и работающий backend.
Повторный запуск сообщает об уже работающем экземпляре, не открывая панель.

СВОИ ШЕЙДЕРЫ
Есть файл? Выберите «Добавить эффект из файла…» и откройте .lumatape.glsl
или .glsl через системный диалог. Файл проверяется и компилируется сразу.
После успеха он появляется в «Эффект». Если игра ещё не выбрана, файл всё
равно сохраняется: выберите «Игра», затем добавленный эффект.
Ошибка проверки не заменяет работающий шейдер. Подробности доступны
в сообщении Windows и «Сервис → Последняя ошибка…».

Нет файла? В README.md, раздел «Свои эффекты», есть готовый пример запроса.
Добавьте описание эффекта, отправьте его выбранной нейросети сами и сохраните
ответ как .lumatape.glsl. Затем выберите «Добавить эффект из файла…».
LumaTape не обращается к AI; отдельной команды копирования запроса в меню нет.
Новые файлы задают готовый вид константами; parameters: []. Старые файлы v1
совместимы. Повторный выбор того же эффекта сохраняет его значения.
Для шейдера с coordinates: "warp" сначала самостоятельно выберите
«Настройки → Искажения изображения → Разрешить произвольные искажения», затем эффект.
Произвольные искажения автоматически не разрешаются.
Примеры: examples/shaders. Спецификация: docs/SHADER_SPEC.md.
Shadertoy/ReShade требуют адаптации. В v1 нет внешних текстур, циклов
и истории кадров; произвольный GLSL не является безопасной песочницей.

НАСТРОЙКИ И КЛАВИШИ
В «Настройки»: форма экрана, формат 4:3, искажения изображения, масштаб, исходные
пропорции старых игр, обработка и горячие клавиши. Выбор применяется сразу.
В «Настройки → Искажения изображения» оба варианта сохраняют работу клавиатуры
и мыши. Режим «Точные клики» ограничивает изменения картинки ради совпадения
кликов.
«Разрешить произвольные искажения» снимает ограничения, но видимая кнопка
может перестать совпадать с местом клика. Это не выбор устройства ввода.
«Разрешение Windows…» действительно меняет видеорежим после предупреждения.
«Подтвердить видеорежим» появляется только на эти 15 секунд; без подтверждения
прежний режим восстанавливается. Полосы/растяжение зависят от драйвера/монитора.
Маска и «Изменить окно игры» убраны из меню. Оконный 4:3 снят из-за
повторного мерцания полей; задавайте формат в самой игре. Старые JSON-профили
и их восстановление совместимы. 1280×1024 — 5:4, а не 4:3.
Для выпуклого CRT с мышью выберите «Настройки → Искажения изображения → Точные клики»
и «Форма экрана → Выпуклый CRT». Нужен Full: Auto, GPU или совместимый CPU.
LumaTape рисует системный курсор на выпуклом изображении, не меняя Windows-ввод,
движения, клики, колесо или захват мыши. Выключение возвращает обычный курсор.
Скруглённый CRT сохраняет положение пикселей. Crop/Stretch, нестандартный DAR
и свои warp-шейдеры требуют «Разрешить произвольные искажения».
Для warp проекции курсора нет; универсальное переназначение игрового ввода
не поддерживается. Пометка автора preserve сама по себе не доказывает
точность кликов; проверяйте шейдер на тестовой сцене.
Поверхность эффекта всегда остаётся в реальной клиентской области окна.
«Вписать целиком» сохраняет весь кадр, «Заполнить с обрезкой» отбрасывает края.
«Пропорции старых игр → 4:3» полезно для 320×200; обычно оставляйте «Как в окне».
Выбор всего монитора оставлен в отдельном legacy/CLI-приложении.
Встроенного предпросмотра и A/B-панели нет; тестовая сцена — отдельное окно.

Новый профиль: Ctrl+Shift+9 — переключить; Ctrl+Shift+0 — отключить и восстановить.
Старые назначения сохраняются. «Настройки → Горячие клавиши» показывает
сохранённые сочетания с подписями действий, а ниже предлагает
пары Ctrl+Shift+9 / Ctrl+Shift+0 и Ctrl+Alt+F9 / Ctrl+Alt+F10. Существующая
пользовательская пара сохраняется до явного выбора другой. Записи нового
произвольного сочетания нажатием в трее нет. При конфликте прежняя пара остаётся.
«Сервис → Проверить горячие клавиши…» различает регистрацию Windows и
фактическое получение. Во время проверки команды работают по-настоящему.
На Mac Alt — Option, Control — не Command; F-клавишам иногда нужен Fn.
Доставка зависит от Parallels; приложение не меняет настройки хоста.

ХРАНЕНИЕ И ДИАГНОСТИКА
Настройки/лог: %APPDATA%\LumaTape; шейдеры: %LOCALAPPDATA%\LumaTape\Shaders.
Запись рядом с EXE не нужна. JSON/CLI сохраняют прежние значения; intensity=0
обходит фильтр и форму, сохраняя независимый 4:3. Чтение профиля его не меняет.
«Сервис → Скопировать диагностику»: текст без снимков, полных путей и названий
чужих окон. Автоматической отправки нет. В «Сервис» также доступны версия
приложения, последняя ошибка и обновления. Канал обновлений пока не настроен;
проверка не обращается в сеть. В настроенной сборке тихая проверка идёт через20с
после запуска; установка — только после подтверждения и для NSIS-версии.
ZIP обновляется распаковкой нового комплекта отдельно. Подробности: docs/UPDATES.md.

ГРАНИЦЫ ПРОВЕРКИ
Windows 10 2004 (19041)+, OpenGL 3.3, SDR. HDR, exclusive fullscreen,
захват монитора в Full и внедрение в игры не поддерживаются.
CPU-совместимость Parallels не доказывает работу физического GPU,
реальных игр, дисплеев и всех DPI. Новый трей требует собственной runtime-проверки;
исторические проверки прежней панели не подтверждают его работу.
Проекция не воспроизводит тайминг анимированных системных курсоров;
XOR-инвертирующие курсоры не поддерживаются. Физический ввод с Mac и отображение
курсора хостом Parallels требуют отдельной проверки.
Версия и SHA256 указаны в выпуске и файлах комплекта. Протокол Windows
и границы проверки: docs/WINDOWS_VALIDATION.md.
Сборка: README.md. Сохранённые HTML/React-прототипы в запуске не используются.
