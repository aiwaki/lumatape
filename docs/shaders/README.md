# Свои эффекты в LumaTape

[Документация](../README.md) · [English](README.en.md)

Выберите «Добавить эффект из файла…» и откройте файл `.lumatape.glsl`.
После проверки и компиляции эффект появится в меню «Эффект». Если игра ещё
не выбрана, файл сохранится в библиотеке — его можно включить позже.
Ошибка импорта оставляет работающий эффект на месте.

Чтобы создать эффект с нейросетью, используйте пример запроса ниже и замените
описание эффекта на своё. Сохраните ответ как `.lumatape.glsl` и импортируйте
через меню. LumaTape сам не обращается к нейросетям.

<details>
<summary>Пример запроса нейросети</summary>

```text
Создай готовый шейдер LumaTape v1: тёплый CRT с заметными строками,
мягким свечением и лёгким шумом. Верни только один файл .lumatape.glsl.
Это однопроходный GLSL 330 core, SDR sRGB; не Shadertoy и не ReShade.
В начале нужен комментарий с JSON:
/* LumaTape
{"version":1,"name":"Тёплый CRT","description":"Строки, свечение и шум","coordinates":"preserve","parameters":[]}
*/
Затем функция vec3 lumatape(vec2 uv), возвращающая RGB sRGB.
Приложение предоставляет:
- uv: 0..1, начало сверху слева;
- vec3 ltSample(vec2 uv): цвет игры, crop/clamp уже учтены;
- vec2 ltResolution: размер области изображения в физических пикселях;
- float ltTime: время в секундах.
Вид эффекта задай константами, без пользовательских параметров.
Оболочка сама применяет alpha, CRT-форму, формат и интенсивность.
Не добавляй #version, main, uniforms, in/out/inout, layout, discard,
директивы, gl_*, frag, uSource*, внешние текстуры или историю кадров.
Циклы for/while/do запрещены: небольшое число выборок разверни вручную.
Разрешены helper-функции и обычная GLSL-математика. Размер до 64 KiB.
Для этого цветового эффекта сохрани coordinates:"preserve"
и не перемещай изображение.
```

</details>

[Примеры шейдеров](../../examples/shaders) · [Спецификация LumaTape Shader v1](../SHADER_SPEC.md)

Файлы Shadertoy/ReShade требуют адаптации. Произвольное геометрическое искажение
(`coordinates: "warp"`) нужно явно разрешить в настройках; точные клики для него
не гарантируются. Проверяйте новые эффекты на тестовой сцене.
