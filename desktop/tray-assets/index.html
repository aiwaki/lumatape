For a fullscreen effect, use the game's borderless mode. LumaTape follows the window size.

4:3 format

Resizes the window itself without changing Windows resolution. A fullscreen window will become smaller too. If the game keeps a wide image, select 4:3 in its settings too.

Windows resolution

Changes the resolution of the game's display. If you do not confirm within 15 seconds, Windows returns to the previous resolution. Stretching and bars depend on your display and graphics driver.
